# 🚀 NitroBoost — معزّز ألعاب احترافي

**الإصدار الحالي: v1.13.0 (versionCode 16)** — لقطة telemetry موحدة وتحليل frame pacing مبنيان على قراءات فعلية مع إبقاء القيم غير المتاحة null. نتائج الأداء تعتمد على الجهاز وإصدار النظام؛ لا نضمن زيادة FPS على كل جهاز.

**NitroBoost** تطبيق Android أصلي (Kotlin + Material 3) مبني من الصفر مع
خيارات ضبط قابلة للتخصيص، **سجلّ تغييرات (Journal)** و**استعادة تلقائية**
للتغييرات التي ينفذها المحرك. النتيجة تتأثر بقدرات الجهاز وسياسات الشركة المصنّعة؛
لا يُفترض تحسن FPS أو البطارية دون قياس على الجهاز نفسه.

> 📱 للتفاصيل الكاملة: [NitroBoost/README.md](NitroBoost/README.md)

## لماذا NitroBoost أفضل؟

| الميزة | Game Speed X / RevBoost | NitroBoost |
|---|---|---|
| الاستعادة الآمنة | جزئية / يدوية | **سجلّ لكل تعديل + استعادة بضغطة + استعادة تلقائية عند الخروج** |
| الحماية من الحرارة | حصر (Throttle) | **تدرّج ذكي (De-escalation) يحفظ ما يمكن حفظه** |
| الذاكرة | قتل العمليات فقط | **تنظيف كاش التخزين (ليس RAM) + إنهاء اختياري + قائمة حماية** |
| الشاشة | معدل تحديث ثابت | **معدل تحديث وكثافة اختياريان؛ `0` يبقي سياسة الجهاز** |
| الرصد | لا شيء | **FpsOverlay: FPS/CPU/RAM/حرارة/Ping فوق اللعبة** |
| الوضع الصامت | DND فقط | **DND + إيقاف إشعارات الحركات + Data Saver + Battery Saver** |
| التخصيص | محدود | **17 ملف جاهز + إنشاء ملفات مخصصة لكل لعبة** |
| اللغات | — | **عربي + إنجليزي** |
| الرصد | — | لقطات monitor كل ثانية؛ مصادر FPS/الشبكة/الحرارة لها معدلات أبطأ لتقليل العمل غير الضروري |

## البناء

افتح مجلد `NitroBoost/` في **Android Studio** (Koala أو أحدث) → انتظر المزامنة →
`Run`. التفاصيل الكاملة وتثبيت Shizuku في [NitroBoost/README.md](NitroBoost/README.md).

## هيكل المستودع

- `NitroBoost/` — التطبيق ومشروع Android Studio الكامل.
- `reference/` — ملفات مرجعية مفككة للمراجعة فقط؛ ليست جزءًا من تطبيق NitroBoost.

## الأمان

كل تعديل على النظام (Settings، /sys، DND، Battery Saver…) يُسجَّل في
`journal.json` بقيمته السابقة وأمر الاستعادة. عند الخروج من اللعبة — أو عند
الضغط على «استعادة كل شيء» — تُستعاد القيم بالتراس عكسي، وأي عنصر يفشل **يُبقى**
في السجل حتى الاستعادة اليدوية.
