# 🚀 NitroBoost — معزّز ألعاب احترافي

**الإصدار الحالي: v1.24.1 (versionCode 32)** — يدعم Android 7.0 / API 24 مع استهداف Android 16 / API 36. في هذا الإصدار: حالة اتصال Shizuku صريحة مع تحديث فوري للواجهة عند قطع الاتصال أو استلام نتيجة الإذن، ونتائج الأوامر تُقرأ من رمز الخروج الحقيقي فقط، مع تقليل عمل الخمول (فترات استطلاع متكيفة، بدون اختبار شبكة أثناء الخمول، بدون أوامر shell للفحص) من دون المساس بمحرك التعزيز أو بحدود الحماية الحرارية. v1.24.0 أضاف سجل جلسات لكل لعبة.

**NitroBoost** تطبيق Android أصلي (Kotlin + Material 3) مبني من الصفر مع
خيارات ضبط قابلة للتخصيص، **سجلّ تغييرات (Journal)** و**استعادة تلقائية**
للتغييرات التي ينفذها المحرك. النتيجة تتأثر بقدرات الجهاز وسياسات الشركة المصنّعة؛
لا يُفترض تحسن FPS أو البطارية دون قياس على الجهاز نفسه.

## لماذا NitroBoost أفضل؟

| الميزة | Game Speed X / RevBoost | NitroBoost |
|---|---|---|
| الاستعادة الآمنة | جزئية / يدوية | **سجلّ لكل تعديل + استعادة بضغطة + استعادة تلقائية عند الخروج** |
| الحماية من الحرارة | حصر (Throttle) | **تدرّج ذكي (De-escalation) يحفظ ما يمكن حفظه** |
| الذاكرة | قتل العمليات فقط | **تنظيف كاش التخزين (ليس RAM) + إنهاء اختياري + قائمة حماية** |
| الشاشة | معدل تحديث ثابت | **معدل تحديث وكثافة اختياريان؛ `0` يبقي سياسة الجهاز** |
| الرصد | لا شيء | **FpsOverlay: FPS/CPU/RAM/حرارة/Ping فوق اللعبة** |
| الوضع الصامت | DND فقط | **DND + إيقاف إشعارات الحركات + Data Saver + Battery Saver** |
| التخصيص | محدود | **16 ملفًا جاهزًا + إنشاء ملفات مخصصة لكل لعبة** |
| اللغات | — | **عربي + إنجليزي** |
| الرصد | — | لقطات monitor كل ثانية؛ مصادر FPS/الشبكة/الحرارة لها معدلات أبطأ لتقليل العمل غير الضروري |

## البناء

افتح مجلد `NitroBoost/` في **Android Studio** (Koala أو أحدث) → انتظر المزامنة →
`Run`. التفاصيل الكاملة وتثبيت Shizuku في [NitroBoost/README.md](NitroBoost/README.md).

## هيكل المستودع

- `NitroBoost/` — التطبيق ومشروع Android Studio الكامل.
- `reference/` — ملفات مرجعية مفككة للمراجعة فقط؛ ليست جزءًا من تطبيق NitroBoost.
- `AGENTS.md` و`.agents/` — منظومة المهارات الهندسية المستقلة (13 مهارة في `.agents/skills/`)،
  وملف `AGENTS.md` في الجذر هو نقطة الدخول الإلزامية لأي وكيل يعمل على المستودع: يحدد
  المهارات ومتى تُستدعى، دورة التطوير `DISCOVER→…→LEARN`، نموذج الفريق، والقواعد
  غير القابلة للتفاوض (`.agents/RULES.md`). وتُفرض سلامة المنظومة آلياً في CI عبر `tools/verify_skills.py`.
- `tools/` — أدوات التحقق على مستوى المستودع (منها `verify_skills.py` لفحص سلامة منظومة المهارات).

## الأمان

التغييرات القابلة للعكس التي تمر بمسارات التسجيل تحفظ القيمة السابقة وأمر
الاستعادة في `journal.json`، ثم تُستعاد بترتيب عكسي؛ ويظل العنصر الفاشل في
السجل. هذا لا يشمل الأفعال أحادية الاتجاه مثل trim أو force-stop، ولا يعني
أن كل كتابة تسجل قبل التنفيذ.
